# 웹소설 네비게이터 (Story Bible Navigator)

회귀 웹소설 스토리바이블을 휴대폰에서 관리하는 **설치형 웹앱(PWA)** 입니다.
"Story Bible Project Constitution v1.0" 원칙(단일 진실 원본)에 따라 모든 화면과
내보내기 파일이 하나의 데이터에서 파생됩니다.

## 주요 기능

- 🏠 **홈 대시보드** — 통장 잔고, 열린 이슈, 집필 진행, 장기 목표, 헌장(Constitution)
- 👥 **인물 선택** — 인물 목록에서 선택 → 상세 설정/태그/관계 확인
- 🕸️ **인물 관계도** — 주인공 중심 SVG 네트워크 (노드 클릭 시 인물 상세로 이동)
- 💰 **투자 & 통장** — 투자 5단계 로드맵 + 통장 잔고/거래 내역
- ⚔️ **적 리스트** — 7보스 + 최종보스 진행 상태
- 🧩 **중요 이슈(떡밥)** — 회수해야 할 복선 추적
- ✏️ **편집 & 내보내기** — 스토리 파일/마스터 DB 수정 후
  - `마스터 md`, `통합요약 md` 개별 다운로드
  - **`스토리바이블.zip`** 한 번에 다운로드 (모든 md + JSON 백업 포함)

## 왜 Streamlit이 아니라 PWA인가?

요구사항이 "휴대폰에서 작동하는 앱"이기 때문입니다. Streamlit은 파이썬 서버가
항상 실행돼야 하므로 폰에 설치하는 앱으로는 부적합합니다. PWA는 홈 화면에 설치
가능하고, 오프라인에서 동작하며, 편집/ZIP 내보내기를 서버 없이 클라이언트에서
처리합니다.

## 실행 방법

정적 파일이라 어떤 웹서버로도 열 수 있습니다.

```bash
cd webnovel-navigator
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

### 휴대폰에 앱으로 설치

1. 같은 네트워크에서 폰 브라우저로 접속 (또는 정적 호스팅에 배포)
2. **iOS Safari**: 공유 → "홈 화면에 추가"
3. **Android Chrome**: 메뉴 → "앱 설치" / "홈 화면에 추가"

## 데이터 저장

편집 내용은 브라우저 `localStorage` 에 저장됩니다. "기본값으로 초기화"로 언제든
원본으로 되돌릴 수 있고, `스토리바이블.zip` 의 `story-bible.json` 으로 백업됩니다.

## 파일 구조

| 파일 | 설명 |
|------|------|
| `index.html` | 앱 셸 (상단 앱바 + 하단 탭바) |
| `style.css` | 모바일 우선 다크 UI |
| `data.js` | 스토리바이블 기본 데이터 (단일 진실 원본) |
| `app.js` | 라우팅/렌더링/편집/마크다운 생성 |
| `zip.js` | 순수 JS ZIP 생성기 (무압축, 오프라인) |
| `sw.js` | 서비스 워커 (오프라인 캐시) |
| `manifest.webmanifest` | PWA 설치 매니페스트 |
